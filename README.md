# Smart QR Code-Based Staff Attendance Management System

A web-based staff attendance management system designed for the Department of Information Technology (IFT), FUTO.

The system uses time-limited QR codes and geolocation verification to provide a modern, secure, and efficient way to record and manage staff attendance.

## Features

- Admin and Staff role-based authentication
- Email/password and Google authentication
- Email verification and password reset
- Secure admin management
- Dynamic time-limited QR codes
- QR code scanning using device camera
- IFT building geolocation verification
- Duplicate and expired QR scan prevention
- Real-time attendance records
- Staff attendance history and statistics
- Admin dashboard and analytics
- Staff management
- Search and filtering
- Responsive desktop and mobile interface
- Dark/light mode
- Firebase Authentication and Firestore backend

## Tech Stack

- React.js
- Vite
- JavaScript
- Vanilla CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Cloud Functions
- Firebase Storage
- QR Code technology
- Browser Geolocation API

## Project Purpose

The system provides a low-cost alternative to traditional biometric attendance systems by combining QR-code authentication, geolocation verification, and Firebase cloud services.
